# 02 — Public Workflow

## Purpose

This public workflow shows how an AI-generated response can be reviewed before it is accepted as reliable, usable, or ready for action.

The workflow is intentionally simplified for public demonstration.

It shows the visible review process while protecting proprietary prompts, internal scoring logic, private control rules, and protected framework architecture.

---

## Public Evaluation Workflow

```text
USER REQUEST
↓
AI RESPONSE
↓
INTENT CHECK
↓
INSTRUCTION CHECK
↓
FACT / ASSUMPTION CHECK
↓
RELIABILITY CHECK
↓
USABILITY CHECK
↓
HUMAN REVIEW
↓
DECISION
↓
APPROVE / REVISE / REJECT
